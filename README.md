# 🦟 Dengue Fever Outbreak Analysis Using Machine Learning

## 📌 Project Overview

NTUC LearningHub Associate AI/ML Developer Capstone Project.

This project analyses **Singapore Dengue Fever outbreak data from NEA** to identify dengue cluster patterns, visualize outbreak hotspots, and apply machine learning models for prediction and analysis.

---

## 🎯 Objectives

- Analyse dengue cases distribution in Singapore
- Identify high-risk dengue clusters
- Perform exploratory data analysis (EDA)
- Apply machine learning for outbreak prediction
- Visualize dengue cluster patterns

---

## 📂 Dataset

Source:
**National Environment Agency (NEA) Singapore Dengue Cluster Dataset**

Dataset contains:

- 399 dengue cluster records
- Location data (Latitude & Longitude)
- Dengue case counts
- Cluster information
- Date and month details
